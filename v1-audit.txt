1. ARSITEKTUR
────────────────────────────────────────────────────────────────────────────────

Stack:
  Frontend   : Streamlit (Python) — single-file app.py 17k+ baris
  Backend    : FastAPI (backend/main.py, 163 baris) — mostly unused oleh UI
  Database   : PostgreSQL (prod) / SQLite (dev/fallback)
  Auth       : streamlit-authenticator + users.yaml (YAML file, bukan DB)
  Sidecar    : Java JLC JLCPCB SDK — port 8089 (/component/info)
  Integrasi  : Mouser API (backend/mouser.py), DigiKey OAuth2 (backend/digikey.py)

Data flow aktual:
  Streamlit → langsung query SQLAlchemy/SQLite → render
  Streamlit → fetch ke Java sidecar (port 8089) untuk LCSC price
  Streamlit → fetch ke Mouser/DigiKey API langsung dari Python
  FastAPI backend hampir tidak dipakai dari frontend (bypass)

Deployment: Docker Compose (db + api + jlc-sidecar), Streamlit jalan lokal

2. FITUR PER TAB
────────────────────────────────────────────────────────────────────────────────

Role super  → semua tab termasuk Costing
Role admin  → semua kecuali Costing
Role user   → hanya Sets, Products (read-only), docs

TAB 1: Sets
  - List semua Config Set + parent inheritance
  - Filter sidebar: multi-select sets, products, categories, packages, values, suppliers, search
  - View BOM per set (expand inherited parent)
  - Multi-set union: gabungkan beberapa set, tampilkan total qty per item
  - Download Excel BOM (single set atau union)
  - Format Excel: multi-sheet, GSPE format khusus
  - Klik item → buka detail item

TAB 2: Set Configurator
  - Buat/edit Config Set
  - Pilih parent set (inheritance)
  - Tambah produk + qty ke set
  - Override: set_qty / add / remove per item
  - Save as new / overwrite existing

TAB 3: Products
  - List semua produk (family + variant view)
  - Filter by family, variant, supplier, value, package, search
  - View BOM rows per produk
  - Lihat usage: set apa yang pakai produk ini
  - Download CSV BOM per produk

TAB 4: Product Builder
  - Buat / clone / hapus produk
  - Attach / detach items ke produk
  - Edit quantity per item dalam produk
  - Merge dua produk jadi satu
  - Rename produk

TAB 5: Items
  - Browse semua komponen (264 items dari UniqueItems)
  - Filter: kategori, supplier, package, value, search
  - Pagination
  - Edit harga langsung di tabel (inline edit)
  - Edit field lain: wh_qty, wh_location, suppliers
  - Klik item → panel detail (price breaks, alternatives, links)
  - LCSC price lookup (via Java sidecar C-code)
  - Mouser search (via API key)
  - DigiKey search (via OAuth2)
  - Apply harga hasil lookup ke item

TAB 6: Costing (super only)
  - Hitung total cost per produk dan per set
  - Multi-currency: rates dari rates.yaml (500+ currency + crypto)
  - Tiered pricing: pick_price_from_breaks() berdasarkan qty
  - Mode: respect MOQ, use alternatives, prefer in-stock
  - Temp swap: ganti satu item dengan alternatif tanpa save
  - Supplier breakdown: cost by supplier
  - Export costing ke Excel

TAB 7: Admin
  - Import Excel (enhanced_master_bom.xlsx format)
  - Backup ke Excel (5 sheet: Items, Products, ProductItems, ConfigSets, ConfigSetItems)
  - Changelog: audit trail semua perubahan field
  - Warehouse: edit wh_qty, wh_location per item
  - Mouser API key management (simpan ke file lokal)
  - DigiKey credentials management (client_id + secret ke file lokal)
  - Sync UniqueItems: sinkronisasi xlsx ↔ DB
  - User management: hanya bisa lihat, tidak bisa edit dari UI

TAB 8: Analytics
  - Summary metrics: total items, products, sets, BOM rows
  - Supplier breakdown (bar chart)
  - Category breakdown (bar chart)
  - Missing prices by set (table dengan % coverage)

TAB 9: Superset
  - List semua Superset (group dari beberapa Config Set)
  - View komposisi: set apa + qty multiplier
  - Export BOM CSV
  - Export ZIP (per-set files)
  - GSPE format export

Sidebar Pages (belum full di v1):
  Hardware Documentation — upload/manage docs per produk (Datasheet, BOM, Gerber, dll)
  Software Documentation — SBOM tracking, per-software docs

3. STRUKTUR DATA (DB MODELS)
────────────────────────────────────────────────────────────────────────────────

Product
  id, name (unique), slug, created_at, updated_at

Software
  id, name, slug, category, website_url, license, notes

ProductRelation
  parent_id → products.id
  child_id  → products.id
  relation  : 'variant' | 'accessory'

Item
  stable_id (PK, 8-char hex hash)
  part_number, product_name, value, description
  alternate (string, belum dipakai penuh)
  category, package
  stock_code, suppliers (semicolon-separated), links (semicolon-separated)
  price_min, price_currency
  manufacturer, stock_qty, image_url, stock_status, stock_available
  wh_qty, wh_location
  supplier_prices (JSON string: {supplier: {moq, price, breaks[], currency}})
  alternatives (semicolon-separated stable_ids)

ProductItem
  product_id + stable_id (composite PK)
  quantity_sum, references, notes
  alternatives (JSON, item-level alt mapping)

Document
  id, product_id|software_id|set_id (nullable FK)
  type: Datasheet|Manual|Dimension|BOM|Gerber|Firmware|Software|3D
  storage_kind: 'file' | 'url'
  path_or_url, checksum, uploaded_by

ChangeLog
  entity, entity_id, field, old_value, new_value
  changed_by, changed_at, context (JSON)

ConfigSet
  id, name (unique), parent_set_id (self-FK, nullable)
  notes, created_by, created_at, updated_at

ConfigSetItem
  set_id → config_sets.id (CASCADE)
  order_index, main_product_id → products.id
  op: 'set_qty' | 'add' | 'remove'
  variant_ids (JSON list of product IDs)
  qty

Superset
  id, name, notes, created_by, created_at, updated_at

SupersetItem
  superset_id → supersets.id (CASCADE)
  order_index, set_id → config_sets.id
  qty

4. LOGIC KRITIS
────────────────────────────────────────────────────────────────────────────────

Stable ID generation (stable_id):
  8-char hex = sha256(normalize(part_number + product_name + value + package + stock_code))[:8]
  Collision handling: append suffix jika clash

Pricing engine (utils/pricing.py):
  pick_price_from_breaks(breaks, qty) — cari break yang cocok dengan qty
  best_price_option_for_entry(entry, qty, respect_moq) — hitung effective order qty
    after MOQ + order_multiple rounding
  supplier_prices field = JSON: {"LCSC": {"moq":1, "price":0.05, "breaks":[...]}}

Currency conversion (utils/currency.py):
  rates.yaml — 500+ currency + crypto, update berkala
  supplier_currency.yaml — mapping supplier → default currency
  Fallback: hardcoded DEFAULT_RATES (USD/IDR/CNY/EUR)

Set inheritance resolution (compute_set_bom_df):
  Walk parent_set_id rekursif
  Child overrides parent dengan op: add/remove/set_qty

Superset BOM (compute_superset_bom):
  Aggregate semua set × qty multiplier
  Handle duplicate items: sum qty across sets

Auth (utils/auth_stauth.py):
  users.yaml → role: user/admin/super
  streamlit-authenticator library
  Password hash: SHA256 dengan salt per user

5. PAIN POINTS — V1
────────────────────────────────────────────────────────────────────────────────

[P1 — KRITIS] Satu file 17.409 baris
  app.py menyimpan semua: UI, business logic, DB queries, auth, export, API calls
  Tidak bisa di-test unit, sulit debug, tidak bisa parallel dev

[P2 — KRITIS] Streamlit re-render seluruh page setiap interaksi
  Setiap klik → seluruh Python dijalankan ulang
  State disimpan di st.session_state (fragile, tidak persisten)
  Filter sidebar reset saat pindah tab

[P3 — TINGGI] Auth via YAML file
  users.yaml → tidak ada UI untuk manage user
  Password reset harus edit YAML manual
  Tidak ada session expiry proper
  Tidak bisa dipakai di luar Streamlit

[P4 — TINGGI] FastAPI backend hampir tidak dipakai
  Frontend bypass API → query DB langsung
  Backend ada tapi tidak konsisten dengan state UI
  Tidak ada JWT, tidak ada CORS yang proper

[P5 — TINGGI] supplier_prices sebagai JSON string di kolom teks
  Sulit di-query (tidak bisa WHERE by supplier)
  Tidak ada schema enforcement
  Parsing manual di setiap tempat

[P6 — MEDIUM] alternatives sebagai semicolon-separated string
  Susah di-maintain (stale references jika item dihapus)
  Tidak ada foreign key constraint
  Duplikat bisa masuk tanpa validasi

[P7 — MEDIUM] rates.yaml berisi 500+ currency + crypto
  File besar (diload setiap render Streamlit)
  Rate stale (tidak auto-update)
  Crypto rate tidak relevan untuk komponen elektronik

[P8 — MEDIUM] LCSC lookup hanya by C-code
  Tidak bisa lookup by MPN langsung
  User harus tahu C-code dulu

[P9 — LOW] Credential disimpan di file lokal (tidak di DB/env)
  Mouser API key → file lokal di server
  DigiKey credentials → file lokal di server
  Hilang kalau container restart (jika tidak di-mount)

[P10 — LOW] Enrichment state disimpan ke disk per-user
  Autosave/resume enrichment → JSON file per user
  Bukan solusi yang scalable
