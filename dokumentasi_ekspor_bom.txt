DOKUMENTASI FITUR EKSPOR BOM EXCEL - IOTBOMLIST-V2
=====================================================

Dokumen ini menjelaskan secara teknis dan operasional mengenai fitur ekspor Bill of Materials (BOM) ke format Excel (.xlsx) yang berlaku di level PCB maupun level PRODUCT (Gabungan PCB).

-----------------------------------------------------
1. KONSEP HIERARKI DATA
-----------------------------------------------------
Sistem menggunakan terminologi industri manufaktur:
- ITEM: Komponen elektronik tunggal (Resistor, IC, dll).
- PCB (eks-Product): Kumpulan ITEM yang dirakit menjadi satu papan sirkuit.
- PRODUCT (eks-Set): Kumpulan beberapa papan PCB dengan kuantitas tertentu untuk paket produksi akhir.

-----------------------------------------------------
2. LOGIKA PEMILIHAN BARANG (SMART SWAP)
-----------------------------------------------------
Sistem tidak hanya menyalin data, tapi "berpikir" untuk mencari solusi terbaik sebelum data ditulis ke Excel. Logika ini berlaku di semua level ekspor:

A. Deteksi Stok Habis (Out of Stock):
   Sistem menganggap barang KOSONG jika stok supplier bernilai:
   - 0 (Nol)
   - NULL (Tidak ada data)
   - "-" (Tanda strip / NaN dari supplier)

B. Pencarian Alternatif Otomatis (Cheapest & Available):
   Jika sebuah barang harus diganti, sistem akan menyisir seluruh daftar alternatif (bisa lebih dari satu).
   Langkah-langkah:
   1. Mengumpulkan semua kandidat (Barang Asli + Semua Alternatif).
   2. Memfilter dan membuang kandidat yang stoknya Kosong/0/Strip.
   3. Membandingkan harga dari semua kandidat yang memiliki stok.
   4. Memilih barang dengan harga TERMURAH sebagai pemenang untuk diekspor.

-----------------------------------------------------
3. MODE EKSPOR (DUAL MODE)
-----------------------------------------------------

A. Mode Normal (Safe Mode):
   - Prioritas: Desain Engineer.
   - Cara Kerja: Sistem akan selalu menggunakan barang asli selama stoknya masih ada.
   - Swap: Hanya akan mengganti ke alternatif termurah jika barang asli benar-benar KOSONG.

B. Mode Alternative (Cost Down Mode):
   - Prioritas: Penekanan Biaya Produksi.
   - Cara Kerja: Sistem tetap mengecek alternatif meskipun barang asli masih ada stoknya.
   - Swap: Sistem akan otomatis mengganti barang asli jika ada alternatif yang LEBIH MURAH dan PUNYA STOK.

-----------------------------------------------------
4. INDIKATOR WARNA BARIS (HIGHLIGHTING)
-----------------------------------------------------
Untuk memudahkan tim Purchasing melihat status barang secara cepat:

- PUTIH (Normal): Barang asli digunakan dan memiliki stok.
- KUNING MUDA (#FFFFF2CC): Barang hasil SWAP (Penggantian).
  Artinya barang yang muncul di baris tersebut bukan barang asli desain awal, tapi pilihan terbaik yang tersedia.
- MERAH (#FFFF0000): STATUS KRITIS.
  Artinya barang asli habis, DAN tidak ada satupun alternatif yang memiliki stok. Tim Purchasing harus mencari solusi manual.
- BIRU MUDA (Header): Hanya muncul di level Product (Set) sebagai pemisah antar kelompok PCB.

-----------------------------------------------------
5. STRUKTUR KOLOM EXCEL (STANDAR PERUSAHAAN)
-----------------------------------------------------
Format kolom telah disesuaikan agar rapi dan siap pakai:

- Kolom A (No): Nomor urut komponen (1, 2, 3...).
- Kolom B (Mfr): Nama Manufacturer (Pabrikan).
- Kolom C (P/N GSPE): DIKOSONGKAN. Sesuai permintaan untuk diisi manual oleh internal kantor.
- Kolom D (Description): Diisi dengan PART NUMBER agar mudah dibaca oleh tim gudang/purchasing.
- Kolom E (QTY): Jumlah total kebutuhan (sudah dikalikan dengan jumlah PCB di level Product).
- Kolom F (UM): Satuan (Default: PCS).
- Kolom G (Remarks): 
  - Jika barang normal: Diisi link pembelian supplier.
  - Jika barang hasil swap: Muncul catatan "Swapped from [PN-ASLI]".
- Kolom J (DataSheet): Diisi link datasheet komponen jika tersedia.

-----------------------------------------------------
6. FITUR KHUSUS: ALTERNATIF SEMENTARA (TEMPORARY OVERRIDE)
-----------------------------------------------------
Fitur ini digunakan untuk kebutuhan produksi mendesak tanpa merusak database:

- Cara Pakai: Di layar detail PCB, klik ikon 🔍 pada barang merah, pilih barang pengganti dari pasar supplier secara live.
- Sifat: Data hanya disimpan di memori browser (React State).
- Efek: Saat ekspor dijalankan, backend akan dipaksa menggunakan data "mentah" barang sementara ini untuk baris tersebut.
- Keamanan: Database Item tetap bersih. Begitu halaman di-refresh, semua penggantian sementara ini akan hilang.

-----------------------------------------------------
7. RINGKASAN LEVEL PRODUCT (SET)
-----------------------------------------------------
Di level Product, sistem melakukan agregat data:
- Mode Original: Data dikelompokkan per papan PCB.
- Mode Combined: Data dari semua PCB digabung menjadi satu daftar belanja massal, di mana ITEM yang sama akan dijumlahkan kuantitasnya secara otomatis.
