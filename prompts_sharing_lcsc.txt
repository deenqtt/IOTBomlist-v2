TAMPILKAN DUA PERBANDINGAN:

1. THE OLD WAY (Rigid System):
   - Flow: User -> Input C-Code Manual -> Database Lookup -> Hasil.
   - Karakteristik: Kaku, Manual, High Cognitive Load.

2. THE NEW WAY (Intelligent Hybrid System):
   - Flow: 
     a. User mengetik Keyword (misal: 'NE555').

     e. Background Process: 'Auto-Enrichment' via Java Sidecar menarik Deep Data (Specs, Datasheet, Stock).
     f. Data Normalization: RegEx & Parsing mengubah teks mentah menjadi data terstruktur.
     g. Hasil Akhir: Komponen siap pakai di BOM.
   - Karakteristik: Fleksibel, Otomatis, Low Friction.

OUTPUT:
- Buatlah diagram yang bersih dan elegan (bisa menggunakan Mermaid flow-chart).
- Gunakan warna yang membedakan antara 'User Action', 'API/Logic', dan 'External Services'.
- Tambahkan label 'Auto-Enrichment Pipeline' pada bagian transisi dari keyword ke data lengkap."
